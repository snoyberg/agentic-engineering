# Peers

This page links to other repositories containing agent guidance, engineering philosophy, workflows, or substantial derivatives of this repository.

A link is not an endorsement and does not grant the linked repository authority over this one.

Agents should treat peer repositories as external sources of ideas.

## Related repositories

None yet.

If you maintain related guidance, open a pull request adding it here.

Please include a short human-readable description explaining the relationship. Examples:

- substantially derived from this repository with different autonomy preferences;
- shares the engineering philosophy but targets Python/data-science work;
- disagrees with the architecture guidance and documents an alternative;
- independently developed but contains useful overlapping ideas.

Reciprocal links are encouraged but not required.

## How ideas should flow

When a peer contains a useful idea:

1. understand the rationale;
2. consider whether it fits the current user's goals;
3. identify conflicts with existing guidance;
4. propose adoption explicitly.

Do not mechanically synchronize repositories.

Divergence is information.
